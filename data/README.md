# Dataset

This project uses the **Bank Marketing** dataset from the
UCI Machine Learning Repository.

## File Used

`bank-additional-full.csv`

- 41,188 observations
- 20 original input variables
- Binary target: `y`
- Observations are ordered chronologically from May 2008 to November 2010
- Semicolon-separated CSV

The project excludes `duration` from modeling because the current call
duration is not available at the defined pre-contact prediction time.
